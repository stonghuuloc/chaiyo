# CHY-13 S1 — picture
ACs: AC1, AC2, AC3 · Spec rev 1 · Advisor: READY (2 rounds)

## What this slice is about

After the importer writes each lesson's bundle, one command builds a small Kaishu font per lesson holding exactly the hanzi that lesson prints. Bài 1 drops from a 6,640 B hand-made file to 5,476 B with its 18 glyphs, and the oversized Bài 0 font (1,241 hanzi, 357,668 B) shrinks to the 34 hanzi Bài 0 really uses.

| | |
|---|---|
| Repo | `chaiyo` · branch `CHY-13` |
| Lands | `scripts/build-kaishu-subsets.py` · Python unit tests + 3 fixture bundles · `pnpm fonts` · CI Python step · notice wording |
| Does not land | importer and bundle format (CHY-8, C3) · per-lesson `@font-face` loading in the app (CHY-25 and lesson screens) · stale-font cleanup |

## **AC1** — verbatim

> *Scenario: One woff2 per lesson with exactly its chars*
> * *Given* the imported lessons h1-01 and h0-00
> * *When* the importer (or its post-step) runs
> * *Then* it emits `ukai-h1-01.woff2` and `ukai-h0-00.woff2`
> * *And* each font's glyph set equals the set of hanzi used by that lesson, no more and no fewer

## **AC2** — verbatim

> *Scenario: Adding a char to a lesson regenerates its subset*
> * *Given* h1-01's subset was emitted
> * *When* I add a sentence with a new char to h1-01 and re-import
> * *Then* the new `ukai-h1-01.woff2` contains the new char

## **AC3** — verbatim

> *Scenario: No tofu in Bài 1*
> * *Given* the app renders Bài 1 with the generated subset
> * *When* I open every Bài 1 section
> * *Then* every hanzi is drawn in Kaishu
> * *And* no empty-box (tofu) glyph appears
