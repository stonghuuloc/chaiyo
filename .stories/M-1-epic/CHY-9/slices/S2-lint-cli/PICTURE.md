# CHY-9 S2 — picture
ACs: AC4 · Spec rev 1 · Backlog task CHY-9 · stacked on S1

## What this slice is about

Wraps S1's `lintDir` in a command, `pnpm -s lint:content [dir]`, so an author or a script gets one readable line per mistake and a failing exit code. No new rules: it only formats and exits.

| | |
|---|---|
| Repo | `chaiyo` · branch `CHY-9` (after S1) |
| Lands | `scripts/lint-content.ts` · `lint:content` script · `tsx` devDependency · `cli-three` fixture · `cli.test.ts` |
| Does not land | the 9 checks, loader, API (S1) · a CI step (real `content/` not clean yet) · the import CLI (CHY-8) |

## **AC4** — verbatim

> *Scenario: CLI exits non-zero with a readable list*
> * *Given* a content folder with 3 violations in 2 files
> * *When* I run the lint CLI
> * *Then* the exit code is non-zero
> * *And* stdout lists 3 lines, each with file, path, check number and message
