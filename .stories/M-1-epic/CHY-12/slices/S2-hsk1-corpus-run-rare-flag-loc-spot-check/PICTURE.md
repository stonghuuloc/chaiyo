# CHY-12 S2 — picture
ACs: AC4, AC5 · Spec rev 1 · Sub-task none (backlog task CHY-12) · starts after S1 is merged

## What this slice is about

Runs the S1 script over all 505 HSK1 words and makes the result reviewable. Loc sees 20 random entries on a review page, and nothing reaches `content/` until he approves them. Rare senses carry `rare: true`, which is the data the Word Page fold reads.

| | |
|---|---|
| Repo | `stonghuuloc/chaiyo` · branch `CHY-12` (same PR as S1) |
| Lands | `--sample` / `--promote` flags · ≈ 560 word files + `content/sentences/hsk1.yaml` · 2 vitest files · `SPOTCHECK.md` · 4 one-character pinyin fixes |
| Does not land | script, env, rejection, labels (S1) · fold rendering and source link on the Word Page (CHY-32) · import to bundle/Postgres (CHY-8) |

## **AC4** — verbatim

> *Scenario: All HSK1 words have entries with rare senses flagged*
> * *Given* the HSK1 word list
> * *When* the script finishes
> * *Then* every HSK1 word has an entry
> * *And* senses marked rare appear behind the "Xem thêm N nghĩa ít gặp" fold on the Word Page

## **AC5** — verbatim

> *Scenario: Loc spot-checks 20 entries before import*
> * *Given* the generated entries
> * *When* 20 entries are picked at random and shown to Loc
> * *Then* Loc approves them before the entries are imported
