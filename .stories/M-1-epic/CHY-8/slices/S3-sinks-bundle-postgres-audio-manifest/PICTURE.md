# CHY-8 S3 — picture
ACs: AC3, AC7 · Spec rev 1 · Sub-task CHY-8 (slice S3)

## What this slice is about

One lint-clean import is written into three places that must hold the same content: the in-memory store (S2), a folder of JSON bundles, and ten Postgres tables. The import also emits an audio manifest: one key per Sentence, Word and syllable clip. A CLI and the Vercel build wire it together.

| | |
|---|---|
| Repo | `chaiyo` · branch `CHY-8` (after S1, S4, S2; CHY-9 `lintDir` + `tsx`, CHY-13 `pnpm fonts`, CHY-10/11 content) |
| Lands | `src/lib/content/import/`: `audio`, `bundle`, `bundle-sink`, `postgres-sink`, `scope` · `supabase/migrations/…_content_tables.sql` · `scripts/import-content.ts`, `scripts/build-content.sh` · `vercel.json` · CI step · 3 devDependencies (`@electric-sql/pglite`, `pg`, `@types/pg`) |
| Does not land | lint gate, sha, `Sink` contract, memory sink (S2) · derives (S1, S4) · rendering audio, `pnpm fonts`, the app reading `current.json` · loading the 122k Dictionary |

## **AC3** — verbatim

> *Scenario Outline: Each sink receives the same content*
> * *Given* a valid content folder
> * *When* I import it with the <sink> sink
> * *Then* the <output> contains the lesson, words, chars, sentences and questions
>
> | sink | output |
> |---|---|
> | in-memory | store used by tests |
> | JSON bundle | per-lesson JSON files |
> | Postgres | rows in the content tables (per ADR 0002) |

## **AC7** — verbatim

> *Scenario: Audio manifest is emitted*
> * *Given* a valid content folder
> * *When* the import succeeds
> * *Then* an audio manifest is written listing one key `sha256(hanzi|voice)` per Sentence and Word
> * *And* each Sentence's voice is its speaker's Cast voice, else the default narrator
