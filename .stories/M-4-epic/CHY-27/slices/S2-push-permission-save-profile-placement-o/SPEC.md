Nhắc qua Email hoặc Telegram, hoặc bật lại trong cài đặt trình duyệt.". Switching it off again needs no prompt. `'Notification' in window && Notification.permission === 'denied'` when the step opens starts in the denied state. Email, Telegram and "Tiếp" keep working in every case (prototype/o1-welcome.html:122-128).
- [AC5] Migration `supabase/migrations/20261113000000_reminders.sql`: `settings` gains `reminder_time time not null default '21:00'`, `remind_push boolean not null default false`, `remind_email boolean not null default true`, `remind_telegram boolean not null default false`; `profiles` gains `constraint photo_url_size check (length(photo_url) <= 100000)`. The table-level grant (20261110000000_learner_tables.sql:72-73) already covers new columns.
- [AC5] Photo (WAVE-PLAN Q2 assumed A): a chosen file is drawn centre-cropped to 256 × 256 on a canvas and stored as `canvas.toDataURL('image/jpeg', 0.8)` in `photo_url` (icon-512.png gives 14,407 characters); no new file keeps the Google URL (or null). `createImageBitmap` rejects (e.g. HEIC in Chrome) → the previous photo stays and a `Toast` says "Chưa đọc được ảnh.".
- [AC5] `saveWelcome(state, { client, learnerId, now, tz })` (test passes `tz: 'Asia/Ho_Chi_Minh'`) (`learner_id: learnerId` = `session.user.id`; `onboarded_at` and `updated_at` = `now.toISOString()`) (`src/lib/welcome/save.ts`, new): `profiles.upsert({ learner_id, display_name: name.trim(), photo_url }, { onConflict: 'learner_id' })` then `settings.upsert({ learner_id, tz, reminder_time: time, remind_push: push, remind_email: emailOn, remind_telegram: telegram, onboarded_at: now.toISOString(), updated_at: now.toISOString() }, { onConflict: 'learner_id' })` (settings last, so `onboarded_at` is set only when both rows saved); `tz` = `Intl.DateTimeFormat().resolvedOptions().timeZone` (M-3 Q3 A). Either error rejects.
