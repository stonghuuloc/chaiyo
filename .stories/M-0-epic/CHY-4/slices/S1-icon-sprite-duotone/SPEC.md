# CHY-4 S1 — spec
ACs: AC1, AC2  ·  Repo: chaiyo  ·  rev 1

## Behaviour
- [AC1] `pnpm icons` reads Solar icons from the installed `@iconify-json/solar` package and writes one sprite, `src/lib/assets/icons.svg`, containing exactly the 58 ids listed in the script. Verified by: running it, counting `<symbol>`.
- [AC1] Re-running `pnpm icons` leaves the file byte-identical (same bytes, same SHA-256). Symbols are emitted in a fixed order; no timestamp or version string is written. Verified by: hash before/after.
- [AC1] Every `<symbol id>` in the sprite is one the script lists, and every listed id is in the sprite — no hand-added symbol survives a re-run. The file opens with a "generated by `pnpm icons` — do not edit" comment. Verified by: comparing the sprite's ids to the script's list.
- [AC1] Ids keep the legacy scheme: `i-regular-<name>` (Solar line-duotone, or linear for x / caret / check), `i-fill-<name>` (Solar bold-duotone), `i-bold-check`. `TabBar.svelte` and the prototype's `<use href>` ids resolve unchanged.
- [AC1] The logo/PWA PNG script moves to `pnpm brand` and behaves as `pnpm icons` did (same inputs, same `static/brand/*`). Verified by: `pnpm brand` output list equals the pre-change list.
- [AC1] `src/lib/assets/tab-icons.svg`, `scripts/build-tab-icons.mjs` and the `tab-icons` script are removed; `TabBar.svelte` keeps only `<use href>`; `src/routes/(app)/+layout.svelte` mounts `icons.svg` once, aria-hidden, before children (Loc 2026-10-29), so tab roots and pushed screens each have exactly 1 sprite in the DOM.
- [AC2] In every duotone symbol the secondary layer carries `opacity:var(--duo,.5)` and `color:var(--duo-c,currentColor)`; the primary layer carries neither. With nothing set, the layer renders at 50% ink (token defaults `--icon-duo` 0.5, `design.tokens.json:424`).
- [AC2] Setting `--duo` and `--duo-c` on an ancestor changes that layer's computed `opacity` and `color` in the browser (e.g. `--duo:1; --duo-c:#c6301d` → opacity `1`, colour `rgb(198, 48, 29)`). Verified by: DOM check on a rendered `<use>`; unit test pins the markup that makes it possible.
- [LOCK] CHY-3's "anything that moves animates" does not apply: this slice adds no motion.
