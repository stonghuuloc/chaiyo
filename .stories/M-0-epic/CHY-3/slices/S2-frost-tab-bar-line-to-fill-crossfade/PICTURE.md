# CHY-3 S2 — picture
ACs: AC3, AC4 · Spec rev 1 · Sub-task CHY-3.2

## What this slice is about

The empty row of text links from S1 becomes the real tab bar: a frosted pill floating above the phone's home indicator, with each icon fading between its line and filled self when you switch tabs.
Everything that moves animates: icon, label colour, and the bar itself sliding in and out between tab roots and lesson screens.

| | |
|---|---|
| Repo | `chaiyo` · branch `CHY-3` |
| Lands | frost + safe-area bar, 8 extracted icons, `.26s` crossfade, label colour fade, bar slide, motion tokens |
| Does not land | milky selection pill, drag, spring (Q2 → A) · tab root content |

## **AC3** — verbatim

> Scenario: Tab bar is frosted, fixed and safe-area aware
> Given I am on a tab root on a phone with a home-indicator inset
> When I scroll the page content under the tab bar
> Then the bar stays fixed at the bottom
> And the content behind it is blurred through `backdrop-filter`
> And the bar's bottom padding includes `env(safe-area-inset-bottom)`

## **AC4** — verbatim

> Scenario: Selecting a tab crossfades line icon to fill icon
> Given the Hôm nay tab is selected
> When I tap Lộ trình
> Then the Hôm nay icon fades from fill back to line
> And the Lộ trình line icon fades out while its fill icon pops in
> And the motion matches `prototype/tabs.js` when checked on a real phone

## Settled

| Decision | Why / source |
|---|---|
| Fixed full-width `<nav>` carries `padding-bottom: 14px + env()`; the 66px pill inside keeps the prototype's pixels | DISCUSSION.md Q1 → C · `prototype/roots.css:66` |
| No milky pill, no drag, no spring | DISCUSSION.md Q2 → A |
| Ship the 8 used icons (8,120 B), not the 86,614 B sprite | DISCUSSION.md Q3 → B |
| Every state change animates; nothing snaps | Loc, 2026-10-29 → STORY.md Locked |
| Fade is `.26s ease`; reduced motion `.15s`; bar slide cut to 0 under reduced motion | `prototype/roots.css:76,90` · SPEC.md [NFR] |
| Bar slides only, never fades (ancestor opacity would kill the pill's blur mid-slide) | SPEC.md [LOCK] — to confirm on a real phone |
| Blur 24px, saturate 1.75, tint .72 reuse existing tokens | `tokens.css:70-77` |
| No motion token exists, so add `--motion-fade` 260ms and `--motion-fade-reduced` 150ms | `tokens.css` (grep) · SPEC.md [CHORE] |
| TabBar moves from `(tabs)` to `(app)` layout so it can animate out | SPEC.md Open assumptions |
| Cold load of a tab root does not animate | SPEC.md [LOCK] |
