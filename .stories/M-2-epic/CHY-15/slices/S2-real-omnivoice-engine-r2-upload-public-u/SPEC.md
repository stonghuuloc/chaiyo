# CHY-15 S2 — spec
ACs: AC5  ·  Repo: stonghuuloc/chaiyo  ·  rev 2 (stacked on CHY-15 S1 and CHY-14 S2 / PR #63; advisor r1 applied)

## Behaviour
- [AC5] `pnpm render:audio <manifest> [--kind sentence,word,syllable] [--ref-prefix <p>] [--limit N]` reads `{ sha, entries }` (`<out>/<sha>/audio-manifest.json`), keeps the entries matching the filters (`--ref-prefix s-h1-01` keeps Bài 1 sentences; the unfiltered HSK1 manifest holds 1,666 entries, mostly syllables that CHY-17 renders), calls S1's `render` with the OmniVoice engine and the R2 bucket, and prints `<uploaded> uploaded, <skipped> skipped` (exit 0). A `RenderError` prints one `failed: <ref> <message>` line per failure plus the counts and exits 1; a `key mismatch` exits 1.
- [AC5] Bucket adapter `src/lib/audio-renderer/r2.ts`: S3 API, path-style `https://<R2_ACCOUNT_ID>.r2.cloudflarestorage.com/<R2_AUDIO_BUCKET>/<name>`, SigV4 with region `auto`, service `s3`, signed headers `host;x-amz-content-sha256;x-amz-date` and `x-amz-content-sha256` = sha256 of the body (`node:crypto` + `fetch`, no new dependency). `has` = HEAD (200 → true, 404 → false, anything else throws); `put` = PUT with `Content-Type: audio/mpeg` and `Cache-Control: public, max-age=31536000, immutable` (a key is a content hash, never rewritten).
- [AC5] Engine adapter `src/lib/audio-renderer/omnivoice.ts` reads `content/cast.yaml` (CHY-14 S2): `voices.<voice> = { id, instruct, seed, pace }`, `audition`, `overrides[<key>] = { hanzi, voice, say?, seed? }`. Per Cast voice it renders the `audition` text once from `instruct` + `seed` (never retried) into a reference wav cached at `node_modules/.cache/chaiyo-audio/voices/<id>-<seed>-<sha8 of instruct>.wav` (a changed `instruct` or `seed` misses the cache) and uses it as `ref_audio` with `ref_text = audition` for every clip of that voice (ADR 0003 refclip arm). An unknown voice throws `unknown voice: <voice>` for that entry (one failure, run continues). Uploading the reference wavs to R2 is deferred (not needed by the app).
- [AC5] Per clip: text = `overrides[key].say ?? text`; seed = `overrides[key].seed ?? voice.seed`. OmniVoice and Whisper run in one long-lived Python worker (`src/lib/audio-renderer/omnivoice_worker.py`: model loaded once, ops `render` and `transcribe`, JSON lines in and out, device mps), started lazily on the first engine call, so a run where every entry is skipped never starts it and 1,666 clips do not reload the model. The wav is encoded by one ffmpeg call: `atempo=<voice.pace>,loudnorm=I=-16:TP=-1.5:LRA=11`, mono, 24 000 Hz, 48 kbps mp3 (same as `scripts/tts-spike.ts:223`).
- [AC5] Render gate, ported from `scripts/tts-spike.ts` (`audioFaults`, `heard`, `MAX_ATTEMPTS = 4`): an mp3 with a speech-rate or clipping fault, or, for a sentence/word entry without override, whose Whisper transcript differs from `heard(hanzi)`, is re-rendered with the spike's cumulative seed bump (seed, +1000, +3000, +6000: `seed += attempts × 1000` per round), then fails the entry (nothing is put). Entries with an override `seed` or `say` are attempted once and skip the Whisper comparison (chosen by ear, CHY-14 DISCUSSION). Syllable entries skip Whisper (isolated-syllable tone forcing is unreliable, CHAA-55). The audition clip is never retried.
- [AC5] Seam change to S1: `Engine.synthesize` request becomes `{ text, voice, key, kind, hanzi }` (the gate needs `kind` and `hanzi` because `text` is the pinyin `reading` for a split Word); `render` passes them, the fake records them, S1 tests gain the fields.
- [AC5] Public URL: after rendering Bài 1, `GET <R2_PUBLIC_URL>/<key>.mp3` for a Bài 1 sentence key answers 200 with content type `audio/mpeg`, the body decodes (`ffprobe`: mp3, 1 channel, 24000 Hz) and plays; a request with `Origin: <app origin>` returns `access-control-allow-origin` for it.
- [NFR] The audio bucket has its own variables so `scripts/assets_*.py` and the private `chaiyo-assets` keep working: `R2_ACCOUNT_ID` (shared), `R2_AUDIO_BUCKET`, `R2_AUDIO_ACCESS_KEY_ID`, `R2_AUDIO_SECRET_ACCESS_KEY`, `R2_PUBLIC_URL`, plus `OMNIVOICE_PYTHON`. The CLI reads env then `.env` (like `scripts/assets_push.py`); the first empty one prints `<NAME> is missing or empty (set it in .env)` and exits 2 before any engine or network call. No key, secret or signature is printed or logged, including in error messages.
- [CHORE] `package.json` gains `"render:audio": "tsx scripts/render-audio.ts"`; `.env.example` gains the four `R2_AUDIO_*`/`R2_PUBLIC_URL` names (`OMNIVOICE_PYTHON` is already there, `.env.example:17`).

- [AC5] vitest `omnivoice.test.ts` (injected worker, ffmpeg, gate): override `say` and `seed` reach the worker request by key; no override uses the cast seed; unknown voice → `unknown voice: x`; a gate failure retries with seeds base, +1000, +3000, +6000 then fails; an override is attempted once; a syllable entry never calls `transcribe`; the reference wav renders once for many clips; a run where every entry is skipped (fake bucket already full) never starts the worker.
