# CHY-32 S2 — picture
ACs: AC5, AC6 · Spec rev 1 · Plan rev 1 (advisor 2/2) · Lane: words · wave 2

## What this slice is about

The Word Page `/word/<id>` stops being a placeholder: it shows a word's meanings grouped by part of
speech, each with an example, folds rare meanings behind a toggle, and labels where each example came from.
Hold this: the page loads its own lesson from `?lesson=`, so a reload or shared link works.

| | |
|---|---|
| Repo | `stonghuuloc/chaiyo`, `src/routes/(app)/word/[id]/` + `messages/vi.json` |
| Lands | POS groups, examples, rare toggle, Tatoeba link, AI disclaimer, not-found state |
| Does not land | word-card media (S1), example audio (parked), Báo lỗi button (CHY-39.S1) |
| Landing order | after CHY-25.S2 (`catalog` instance) · before CHY-39.S1 (adds Báo lỗi here) |

## **AC5** — verbatim

> **AC5** *Scenario: Word Page renders from the C7 entry*
> *Given* a word has a C7 entry with senses grouped by part of speech
> *When* I open its Word Page
> *Then* I see the meanings grouped by POS, each with an example
> *And* with 3 rare senses I see "Xem thêm 3 nghĩa ít gặp", which reads "Thu gọn" once opened

## **AC6** — verbatim

> **AC6** *Scenario: Examples show their source*
> *Given* an example comes from Tatoeba
> *Then* it carries the label "Tatoeba" linking to `https://tatoeba.org/vi/sentences/show/<id>`
> *And* an AI-written example is covered by "Ví dụ: Tatoeba hoặc AI · AI biên tập, chưa được giáo viên duyệt"
