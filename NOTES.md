# Chaiyo — notes

Personal web app (me + friends, not commercial) to learn Mandarin HSK1 → HSK5, plus HSKK.
Status (2026-10-19): planning done, art style locked. No code yet.

## Product

- Name: **Chaiyo** — how a foreign learner says 加油 jiāyóu ("go for it!"); the joke is on the learner's own accent. Also Thai ไชโย "hooray"; "Chaiyo!" can be the cheer when you pass a gate test. Tagline (draft, login screen): "Biết Hán Việt là biết nửa tiếng Trung".
- Logo: open book with "Chaiyo!" (dark ink + red "!" and swoosh) on a Lantern Red tile (#c52f1c at the edge; was sunflower #fec33e). PNG for now (`assets/brand/source.png`); `scripts/build-icons.sh` derives every PWA icon from it — `logo.png` (rounded, transparent), full-bleed `icon-1024/512/192/32`, `apple-touch-icon.png`, `icon-maskable-512.png` (art in the 80% safe zone), `favicon.ico`. When the SvelteKit app is scaffolded, copy these into `static/` and list 192/512/maskable in the web manifest. The full word turns to mush below 64px; a symbol-only favicon is still open.
- Palette: Lantern Red #c6301d (actions, logo tile) on paper-and-ink neutrals. Logo tile recoloured sunflower → red on 2026-10-22 (Loc: the yellow appears nowhere in the app) via `scripts/recolor-tile.py` then `scripts/build-icons.sh`; yellow original kept as `assets/brand/source-yellow.png`. Exception: Freeze Blue #3f73b0 stays for the Streak Freeze only. Stroke Navy dropped (2026-10-21): stroke order = Ink strokes, red radical.
- Availability (2026-10-21): no learning/Chinese app named Chaiyo found (App Store US/TH/VN, Play, web). Taken: Play restaurant-ordering app "Chaiyo" (ChowNow), Chaiyo Productions (Thai Ultraman film studio), chaiyo.com (1998). Unconfirmed, look free: chaiyo.app/.io/.vn. Trademark unchecked.
- Rejected names: Diandian 点点 (diandian.com/.app/.io taken; DianDian Interactive games; a Spanish Mandarin SRS app "Diǎn Diǎn"), Jiayou (pinyin spelling unfamiliar to non-speakers, generic), Chayo (Mexican nickname, further from jiāyóu), Zìzì (non-speakers say "zee-zee"; French slang for penis), Nihow, Hanzoo (racially loaded), Hảo Hảo (Vietnamese noodle brand).
- Roadmap: Topic → Lessons. Next lesson unlocks only after passing the gate test (≥80%).
- One lesson ≈ 1–1.5h class: warm-up review → 8–15 new words → grammar → dialogue → listening/speaking → writing → gate test.
- Each word: hanzi, pinyin, meaning, Hán Việt, radical breakdown, stroke order, example sentences, picture, TTS.
- "My Lexicon": every learned word/char has a page with backlinks to every lesson it appears in. Every hanzi in any text links to it.
- Mock tests per HSK level; HSKK = record answer → pronunciation scoring.
- Placement test to skip ahead.
- Extras (ranked): SRS review (FSRS, `ts-fsrs`) > tone feedback > tone sandhi shown in pinyin > simplified/traditional toggle > progress dashboard.

## Content

- Syllabus: **HSK 3.0** standard GF0025-2021 (words + numbered grammar points per level). ~4,300 words for L1–5 ≈ 350 lessons.
- Lesson format: HSK Standard Course (HSK标准教程) shape.
- Existing vault to reuse: `~/Documents/second-brain/mandarin/` — 197 char lessons, 407 `chars/`, 56 radicals, `_hanviet.tsv`, `_readings.tsv`, `_ids.txt`, `_hanzi-freq.csv`, build scripts.
- Rules = `_lesson-contract.md` (80% known-chars rule, Hán Việt mandatory, polyphones, sandhi) → becomes the content linter.
- Pipeline: standard → group into topics → script picks words/grammar per lesson → AI drafts → linter → my review → native spot-check → DB.
- Pre-generate lessons per level batch, not all at once. Ship HSK1 (~40 lessons) first.
- Explanation language: **Vietnamese** (UI, explanations, meanings) + Hán Việt. English later; i18n wired from day 1.

## TTS

- Azure Speech zh-CN neural (Xiaoxiao/Yunxi). SSML `<phoneme>` fixes polyphones (行 háng/xíng). No slow-rate files: slow play = client `playbackRate 0.5` on 2nd tap.
- Billing: per request chars; **each 汉字 = 2 chars**; SSML markup counts. Free 0.5M chars/month.
- Cache: split paragraphs by sentence (`。！？；`), key = sha256(sentence|voice), store mp3 in R2. Never stitch per word (breaks tone sandhi).
- Fallback: browser Web Speech API.

## Art — locked

The cast v2 creatures act out each word: **baby panda, red panda, sika deer fawn, takin calf**. No other characters.

Recipe (works):
1. Prompt = one plain sentence, e.g. `The sika deer fawn eating a big red apple in an apple orchard`
2. Append: `. The characters must look exactly like the attached character lineup, in a cute chibi style with thin dark brown outlines and flat pale colours, tiny shiny dot eyes and pink blush ovals. Set them in a richly detailed, cozy illustrated background with warm golden lighting, like a storybook scene. No text, no letters.`
3. Attach `assets/ref/cast.png` (4-cast lineup, labels removed).
4. **Cast by canon role.** Before writing a scene, pick who does what from this table. Never swap roles (wrong: red panda crying while the baby panda comforts it).

| Character | Canon role, use for | Never |
|---|---|---|
| baby panda | Timid crybaby: cries, gets scared, says sorry, fails then tries again, small brave wins. Barely talks ("waa", "iya"). | Comforting others, giving speeches, acting tough |
| red panda | Optimistic talker, the only one who speaks in sentences: greets, explains, encourages, comforts the baby panda, says "it's okay". | Crying first, acting mean |
| sika deer fawn | Chaotic, fearless, loud ("Ura!", "Yaha!"), eats a lot, charges in first, wild celebrating. Doesn't talk. | Sad, calm, polite |
| takin calf | Selfish "cute" troublemaker: demands things ("give me!"), wants to be called cute, fake-innocent, causes trouble. | Kind helper, comforting |

Emotion pairs: someone sad → baby panda is the sad one and red panda comforts. Pass/celebrate → fawn goes wild, baby panda cries happy tears. Demand/rude → takin calf.
Setting: lesson/gate result scenes happen in a classroom (desks, blank green chalkboard, test paper); HSK level results in an exam hall. The scene matches where the event happens, not the lesson topic (no music notes for Bài 0). Prompts: `scripts/gen-result-art.sh`.
Body + cast traps: never write "only characters from the lineup" (model adds fawn/takin calf from the lineup image) → say "draw ONLY the characters named; the lineup is a look reference". Never prompt fingers ("holds up one finger", "thumbs up"): paws are round nubs. State "all about the same height as baby panda", or red panda comes out a head taller.


Without the lineup → 3 ears, fuzzy "stuffed bears", tails swapped between characters. Plain background → boring.
Samples: `assets/samples/` (apple, drink, bank, happy, cafe). Prototype page: `prototype/lesson-images.html`.

Rejected: free stock photos (wrong subjects), hand SVG, gouache, flat halftone, shuimo (beautiful but too abstract for vocab).

## Image generation

- omp's `generate_image` (gpt-image-2), via **openai-codex** (ChatGPT plan) or **opencode-go** (`--model opencode-go/gpt-5.6-luna`, hosted gpt-image-2) → no per-image bill. Batch: one `omp -p` per image, run in parallel.
- Tool is off by default: `omp -p --no-session --auto-approve --config scripts/omp-img.yml --tools generate_image,bash --cwd <dir> "<instructions>"`
- Quirks: ignores image size ~half the time (crop to 3:2 in the app); quality low/medium not controllable.
- Full batch via API instead: gpt-image-2 1536×1024 ≈ $0.005 / $0.041 / $0.165 (low/med/high), Batch API −50%. ~1,000 images medium ≈ $20–40.
